# CodSoft Internship - Task 3: Data Visualization Dashboard

## About this task
This is Task 3 of my Data Analytics internship with CodSoft. The goal was to 
turn the Zomato Bangalore dataset into visual charts that make the patterns 
easy to see at a glance.

## Dataset
Used the cleaned dataset from Task 1 - zomato_cleaned.csv 
(51,588 restaurants across Bangalore).

## What I did
Built 7 different charts covering different parts of the data, then combined 
the main ones into a single dashboard view.

- Bar chart - top 10 areas by number of restaurants
- Pie chart - restaurant type distribution (Delivery, Dine-out, Cafes, etc.)
- Histogram - cost for two distribution
- Histogram - rating distribution
- Scatter plot - cost vs rating relationship
- Bar chart - average rating comparison (table booking vs no booking)
- Line chart - top 10 most popular cuisines
- A combined 6-panel dashboard bringing the key charts together in one view

All charts have proper titles, axis labels, and color coding to make them 
easy to read without needing to explain them separately.

## Tools
Python, Matplotlib, Seaborn, Google Colab

## Files in this repo
- CodSoft_Task3_Visualization.ipynb - all the code
- chart1_top_cities.png through chart7_top_cuisines.png - individual charts
- final_dashboard.png - combined dashboard view
